# バトル神経衰弱（スマホ・PCのSafari / Chromeで遊べる版）

このフォルダは、サーバーなしでも動く「ひとつのゲーム」です。

## いちばん簡単な遊びかた
- `index.html` をダブルクリック（PCのChrome / Safari）。
- そのまま遊べます。データ（コイン・装備・進行）は、そのブラウザに保存されます。

## スマホに「アプリ」として入れる（ホーム画面に追加）
1. このフォルダ全体を、https の静的ホスティングに置きます（無料でできるもの）。
   - GitHub Pages / Netlify（フォルダをドラッグ＆ドロップ）/ Cloudflare Pages など
2. iPhone（Safari）: 共有ボタン →「ホーム画面に追加」
   Android（Chrome）: メニュー →「アプリをインストール」または「ホーム画面に追加」
3. ホーム画面のアイコンから、全画面で起動できます。オフラインでも遊べます（初回だけネットが必要）。

## PCから手元のスマホで試す（同じWi-Fi）
```
cd このフォルダ
python3 -m http.server 8000
```
スマホのブラウザで `http://（PCのIPアドレス）:8000` を開きます。
※ http のままだと「オフライン保存」は働きません（遊ぶだけならOK）。

## 引き継ぎ
ゲーム内の「🔑 パスワード」で、データを文字列にして、別の端末で復元できます。

## ファイル
- index.html … ゲーム本体（1ファイル完結）
- manifest.webmanifest / sw.js / icon-*.png … ホーム画面に追加・オフライン動作用

## いちばん簡単な公開の手順（PCがある場合）
1. このzipを展開して、フォルダにする。
2. ブラウザで https://app.netlify.com/drop を開き、フォルダごとドラッグ＆ドロップ。
   （無料。アカウント登録を求められることがあります）
3. 発行された https://〜.netlify.app のURLを、iPhoneのSafariで開く。
4. 共有ボタン →「ホーム画面に追加」。
※URLを知っている人は誰でも開けます。URLは家族だけに共有してください。
